# Orbitra Home — Firmware Release Notes

Each `##` section describes one firmware release. Format: `<product_id> <version> (<release date>)`.

## robovac-r7 2.4.0 (2026-08-02)

* Multi-floor support increased from 3 to **4 saved floor maps**.
* New *Quiet mopping* option: suction is reduced to Eco while mopping hard floors.
* Improved docking accuracy on dark floors.
* Fixed: schedules sometimes ignored the time zone after daylight saving time change.

## robovac-r7 2.3.0 (2026-03-10)

* New: **carpet avoidance** when the mopping module is attached.
* Fixed: false **E06** (LiDAR blocked) errors in bright direct sunlight.
* Battery runtime estimation in the app is more accurate.

## brewmate-c3 1.3.0 (2026-06-15)

* New drink: **Flat white** (80 ml coffee + 80 ml micro-foam).
* Coffee strength extended from 3 to **5 levels**.
* Descaling program shortened from 35 to about **25 minutes**.

## brewmate-c3 1.2.1 (2026-02-02)

* Fixed: C5 (drip tray full) warning occasionally shown with an empty drip tray.

## airpure-a5 1.0.5 (2026-05-20)

* Auto mode thresholds adjusted: the purifier switches to speed 3 at PM2.5 above 75 µg/m³
  (previously 100 µg/m³).
* Filter life calculation now takes fan speed into account.

## thermosmart-t2 3.1.0 (2026-09-01)

* Geofencing radius is now adjustable from **200 m to 2000 m** (previously fixed at 500 m).
* New monthly energy report in the app.
* Fixed: H3 (Wi-Fi lost) shown for a few seconds after every router restart.

## thermosmart-t2 3.0.2 (2026-04-14)

* Improved two-stage heat pump control (less short cycling).
* Security update for the Wi-Fi module.
